Methodology. Mode 1 (Strict, 195.3h) counts only timestamped inter-turn latency (capped 20 min), live Cisco VPN tunnel sessions and exact tablet pen sessions. Mode 2 (Immersion, 385.2h) adds deliberative reading of 1.09M words at 60–100 WPM with a 1.30× novice assimilation factor (see cognitive_supervision_reading_framework.md), 81.5h live Dichtator SSH development and 12.9h tablet derivations. The green engagement layer inside Mode 2 clusters every human-authored steering message — extracted from transcript.jsonl logs (Gemini Antigravity, WSL + Windows stores) and T3 Code threads — into continuous sessions; gaps ≤ 35 min are merged, because between two steering messages the candidate is reading the agent's reasoning traces, auditing tool output and thinking. Each session then extends past its last prompt by the reading time of the final response it triggered (~130 tokens/min ≈ 100 WPM with thinking, minimum 4 min, capped at one 35-min engagement window, clamped so sessions never overlap or cross midnight). Bare continuation prompts (continue, /compact, ok…) anchor session presence but are excluded from message counts, word sums and the evidence log. The REST shade is punched around the session bands, so late-night proof past 4:00 is never covered.
